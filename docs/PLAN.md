# 묵연(墨緣) — 리빌드 계획

> 한지 위에 먹으로 쓰는 사주. 평생사주 · 신년운세 · 토정비결 · 궁합 · 오늘의 운세.

기존 `saju-service`(평생사주 1종, 단순 카드 UI)를 갈아엎고, **한지 수묵 + 입체 연출** 디자인으로 메뉴 5개짜리 서비스를 새로 만든다.
계산 엔진(`packages/saju-engine`)은 외부 대조 15건으로 검증되어 있으므로 그대로 가져가 기능을 늘린다.

---

## 1. 리서치 요약

### 1-1. 운신 재크롤링 (2026-10-13, Firecrawl)
`tools/crawler/unsin.py`로 메뉴 4개 결과를 다시 받았다. 원문은 `tools/crawler/output/`(gitignore)에만 두고 **구조만** 참고한다. 문구는 쓰지 않는다.

| 메뉴 | 입력 | 결과 구성 |
|---|---|---|
| 평생사주 | 이름·성별·생년월일·시(12지시)·양/음/윤 | 명식표(천간·지지+십신), 오행 막대, 총평, 초·중·말년, 건강·체질, 사회·적성, 성격·성향·인품, 이성·애정, 재물(모으는 법·손실 막는 법·재테크) — 17섹션 세로 나열 |
| 토정비결 | 위 + **대상 연도** | 명식표, 올해 종합운, **월별운(음력 기준, 전년 12월~다음해 2월까지 15칸)**, 연애·직장·건강·소망·대인·처세, 행운의 숫자/불운 숫자, 행운의 색/불운 색(별점) |
| 궁합 | 두 사람 입력 | 두 명식표, **궁합 점수(100점)**, 총평, 항목별(본성·건강·애정·재물·결혼) **사람별 단락** |
| 오늘의 운세 | 기본 입력 | 한마디(사자성어 격언) + 애정·소망·사업·금전 + "오늘 이 방향으로", 어제/내일 이동 |

관찰: 해석은 길지만 **근거(왜 그런지)가 보이지 않는다**. 명식표·오행 막대 외 시각화가 없다. 메뉴끼리 연결(평생→올해→오늘)이 없다.

### 1-2. 다른 서비스 (Chrome으로 확인)
- **포스텔러 만세력**: 일주 별명("정미 · 붉은 양"), 생극 오각형 다이어그램(오행 %와 십성 묶음), 신강/신약 지수와 **분포 내 위치**, 12운성·12신살 행, 합·충·형·파·해·원진·공망을 칩으로 펼쳐 설명, 일진 달력, 지역 경도 보정.
- **점신**: 메뉴를 "타고난 운명 / 궁합 / 소원 / 취업" 같은 목적별로 묶음. 행운의 번호, 이사택일, 연예인 궁합 등 가벼운 재미 요소.

### 1-3. 우리가 다르게 할 것
1. **근거가 보이는 해석** — 문장마다 "왜냐하면 일지 酉와 월지 戌이…" 같은 근거 칩을 붙인다. 용어를 누르면 쉬운 설명.
2. **메뉴가 이어진다** — 한 번 입력한 명식으로 평생 → 올해 → 이번 달 → 오늘까지 내려간다.
3. **연출** — 한지·먹·인장·병풍을 입체로 (아래 2장).
4. **해석 문구는 전부 직접 작성 + Gemini로 개인화**. 외부 서비스 문구 사용 금지.

## 3. 메뉴와 기능

| 메뉴 | 경로 | 계산 (엔진) | 화면 |
|---|---|---|---|
| 평생사주 | `/saju` | 4주, 십신, 지장간, 12운성, **12신살·주요 신살**, **합충형파해·원진·공망**, **신강/신약 점수**, 간이 용신(억부), 대운 | 명판, 오행 오각형, 관계 칩, 병풍 대운, 장(章)별 해석 12개 |
| 신년운세 | `/newyear` | 세운(2027 丁未) × 원국 관계, **월운 12개**, 대운 겹침 | 올해 한 줄, 분야별 점수, 12폭 병풍 |
| 토정비결 | `/tojung` | 작괘(상8·중6·하3 = 144괘), 음력 월별 | 괘 번호 낙관, 괘사, 월별 병풍 |
| 궁합 | `/gunghap` | 일간 생극, 일지·월지 합충, 띠(삼합·육합·원진), 오행 보완도 → **점수(근거 항목별 가감)** | 두 인장, 점수 원, 항목별 비교 |
| 오늘의 운세 | `/today` | 오늘 일진 × 일간 십신·12운성, 원국과 합충 | 한 장짜리 부적 카드, 어제/내일, 일진 달력 |

공통: 입력은 한 번(로컬 저장, 서버 저장 없음). 공유 카드 이미지(OG). 결과 URL은 입력값 쿼리.

### 3-1. 해석 생성
- **룰 기반(기본, 무료, 즉시)**: `packages/reading` — 직접 쓴 문구 데이터(`packages/content`)를 조합. 근거(facts)를 함께 반환.
- **Gemini(선택, 스트리밍)**: 룰 결과 + 근거를 Gemini에 넘겨 자연스러운 개인 문장으로 다시 쓴다. 타로와 같은 REST·SSE 방식(`gemini-2.5-flash`, 모델은 환경변수로 교체), IP당 분당 제한, 실패 시 룰 해석 유지.
- 직접 쓸 문구 분량: 일간 10, 일주 60(기존), 십신 10×위치, 신살 ~15, 합충 관계 ~12, 12운성 12, 토정 144괘(괘사 요약), 오늘 일진 십신 10×등급 3, 궁합 관계 템플릿.

### 3-2. 토정비결 작괘 (검증 필요)
- 상괘 = (세는나이 + 당년 태세수) mod 8, 중괘 = (당년 생월 날수 + 월건수) mod 6, 하괘 = (생일 + 일진수) mod 3, 나머지 0 → 8·6·3.
- 태세·월건·일진 수는 선천수(甲己9 乙庚8 丙辛7 丁壬6 戊癸5 / 子午9 丑未8 寅申7 卯酉6 辰戌5 巳亥4).
- 판본마다 차이가 있어 구현 후 공개된 예시로 대조하고 `docs/saju-rules.md`에 기준을 적는다.

## 5. 폴더 구조

```
saju-service/
├─ apps/web/                         Next.js 앱
│  ├─ src/app/
│  │  ├─ layout.tsx, globals.css     한지 토큰·폰트
│  │  ├─ page.tsx                    산수 첫 화면 + 메뉴 5개
│  │  ├─ saju/ (page.tsx, result/page.tsx)
│  │  ├─ newyear/ · tojung/ · gunghap/ · today/   (같은 패턴)
│  │  ├─ api/interpret/route.ts      Gemini 스트리밍
│  │  └─ og/route.tsx                공유 이미지
│  ├─ src/components/
│  │  ├─ ink/        Hanji, Sansu, BrushText, Seal3D, SealDrop(전환), Byeongpung, Slab
│  │  ├─ form/       BirthForm, PartnerForm, ProfilePicker
│  │  ├─ chart/      PillarSlab, OhaengPentagon, RelationChips, SinsalList, StrengthMeter
│  │  ├─ reading/    Chapter, EvidenceChip, AiReading, TermSheet
│  │  └─ menu/       각 메뉴 결과 화면 조립
│  ├─ src/lib/       gemini.ts, prompts/, query.ts(입력↔URL), profile store
│  └─ src/scene/     (2차) R3F 인장·산수
├─ packages/
│  ├─ saju-engine/   만세력 + 추가: relations/, sinsal/, strength/, yongsin/, iljin/, tojung/, gunghap/
│  └─ reading/       메뉴별 룰 해석 조립 + Gemini 프롬프트 (src/content/ 에 직접 쓴 문구 데이터)
├─ tools/crawler/    unsin.py(구조 조사·간지 대조), to_fixture.py
└─ docs/             PLAN.md, research.md, saju-rules.md
```

기존 `packages/interpretation`(Claude 전용 코드)은 `packages/reading`으로 대체하고 Claude 호출부는 제거했다. 일주 60·일간 10 문구는 `reading/src/content`로 옮겨 재사용. 문구 데이터는 패키지를 따로 두지 않고 `reading` 안에 둔다(조립 코드와 항상 함께 바뀌므로).

## 7. 주의사항
- **저작권**: 외부 서비스 해석 문구·이미지 사용 금지. 크롤링 원문은 저장소에 올리지 않는다.
- **비밀값**: `FIRECRAWL_API_KEY`, `GEMINI_API_KEY`는 `.env`/`.env.local`과 Vercel 환경변수에만.
- **개인정보**: 생년월일은 서버에 저장하지 않는다. AI 요청에도 이름은 보내지 않는다.
- **면책**: 오락·참고용 문구를 모든 결과 하단에.
