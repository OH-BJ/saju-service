# 사주 계산 규칙 결정 사항

유파·서비스마다 다른 부분을 어떻게 정했는지 기록한다. 바꿀 때는 이 문서와 `packages/saju-engine/test`를 함께 수정한다.

| 항목 | 결정 | 구현 위치 |
|---|---|---|
| 년주 경계 | 입춘 절입 **순간** 기준 | `pillars/year.ts` |
| 월주 경계 | 12절 절입 **순간** 기준 (날짜 단위 아님) | `pillars/month.ts` |
| 절기 시각 | lunar-javascript 천문 계산값(베이징시) → UTC 환산 | `calendar/solarTerms.ts` |
| 음력 변환 | 한국천문연구원 기준(korean-lunar-calendar). 중국 음력과 다른 날이 있음 | `calendar/lunar.ts` |
| 시간대 이력 | tzdata(Asia/Seoul)로 서머타임(1948~51, 1955~60, 1987~88)과 UTC+8:30(1954~61) 반영 | `calendar/trueSolarTime.ts` |
| 시 보정 | 기본 `kst30`: 동경 127.5° 태양시 → 子시 = 23:30~01:29 KST. 옵션 `longitude`, `none` | `calendar/trueSolarTime.ts` |
| 자시 | 기본 `split`(야·조자시 구분): 23시대는 당일 일주, 시간은 다음날 일간 기준. 옵션 `unified` | `index.ts` |
| 시간 모름 | 시주 없이 6글자. 년·월주는 정오 기준, 절입일이면 경고 | `index.ts` |
| 지지 십신 | 지장간 정기 기준 (子→癸, 午→丁, 巳→丙, 亥→壬) | `analysis/sipsin.ts` |
| 대운수 | 절입까지 일수 ÷ 3, 개월 단위 반올림 (1일 = 4개월) | `analysis/daeun.ts` |

## 운신(unsin.co.kr) 비교 결과 (2026-10-12, 15건)

12건 일치. 3건은 아래 이유로 엔진이 의도적으로 다르다.

- **c06** 1992-11-07 14시: 입동 절입 12:57 KST 이후라 亥월. 운신은 戌월로 계산.
- **c09** 1988-07-01 午시: 서머타임 기간이라 1시간 보정하면 巳시. 운신은 시계 시각 그대로.
- **c11** 음력 1995 윤8월 15일: 양력 1995-10-09(천문연·lunar-javascript 일치). 운신은 평달(09-09)로 처리.

운신은 `kst30` + `split` 규칙과 일치한다 (시간 모름 입력 시 00:00 → 전날 야자시로 처리하는 것도 확인됨).
