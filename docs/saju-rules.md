# 사주 계산 규칙 결정 사항

유파·서비스마다 다른 부분을 어떻게 정했는지 기록한다. 바꿀 때는 이 문서와 `packages/saju-engine/test`를 함께 수정한다.

## 운신(unsin.co.kr) 비교 결과 (2026-10-12, 15건)

12건 일치. 3건은 아래 이유로 엔진이 의도적으로 다르다.

- **c06** 1992-11-07 14시: 입동 절입 12:57 KST 이후라 亥월. 운신은 戌월로 계산.
- **c09** 1988-07-01 午시: 서머타임 기간이라 1시간 보정하면 巳시. 운신은 시계 시각 그대로.
- **c11** 음력 1995 윤8월 15일: 양력 1995-10-09(천문연·lunar-javascript 일치). 운신은 평달(09-09)로 처리.

운신은 `kst30` + `split` 규칙과 일치한다 (시간 모름 입력 시 00:00 → 전날 야자시로 처리하는 것도 확인됨).

### 토정비결 대조 (2026-10-13)

- 처음에는 세 수를 모두 선천수 합으로 계산했다. 전통 조견표(60갑자 × 태세·월건·일진)와 대조해 보니 **월건수만 선천수 합과 같고**, 태세수·일진수는 지지 몫이 다른 표였다. 위 규칙으로 바꾼 뒤 조견표 180칸 중 179칸이 일치한다. 남은 1칸(乙丑 태세수, 표 20 / 규칙 21)은 같은 丑 다섯 칸이 모두 규칙을 따라 표의 오기로 판단했다.
- 공개된 작괘 예시(음력 1976-08-26생의 2005년: 나이 30 + 태세 乙酉 20 → 2, 작은달 29 + 월건 乙酉 14 → 1, 생일 26 + 일진 丙辰 18 → 2 = **212**)를 날짜 계산까지 그대로 재현한다 (`test/analysis.test.ts`).
- 웹의 다른 계산기 중 jangbowon.com은 하괘에 출생시를 넣는 등 방식이 달라 비교 대상에서 뺐고, cynicalkim.com은 결과를 보려면 광고 시청이 필요해 비교하지 못했다.
